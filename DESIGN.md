## Overview

A dark screen in the Graphite theme: Montserrat headings over Inter body text, a #2e2e2e background with #e0e0e0 text, and #e0e0e0 primary actions. The look comes from the theme's semantic tokens; the content decides the structure.

## Colors

Every colour is a semantic token of the Graphite theme, used through utilities such as `bg-background`, `text-foreground`, `bg-primary` and `border-border`.

## Layout

The structure follows the content: the primary task first, supporting regions after it, aligned to a consistent grid.

Below the tablet breakpoint every multi-column region collapses to a single column in reading order.

## Elevation & Depth

Theme shadows (Graphite default): `0 1px 2px 0 rgb(0 0 0 / 0.05)` at rest, `0 4px 6px -1px rgb(0 0 0 / 0.1), 0 2px 4px -2px rgb(0 0 0 / 0.1)` for floating menus, `0 10px 15px -3px rgb(0 0 0 / 0.1), 0 4px 6px -4px rgb(0 0 0 / 0.1)` for hero cards and modals.

Depth stays quiet: elevation separates layers, it does not decorate.

## Shapes

Radius by role, from the theme's base radius of 0.35rem:

- Buttons, inputs, selects, tabs and tables: `rounded-lg`.
- Cards, panels, list rows and media frames: `rounded-xl`.
- Feature cards and modals: `rounded-2xl`.
- Pills, badges, avatars and chips: `rounded-full`.
- Page and section backgrounds are never rounded; one radius is never used for everything.

## Components

- **Primary action:** `bg-primary text-primary-foreground` (the theme's button colour), `rounded-lg`.
- **Secondary action:** `bg-secondary text-secondary-foreground`, or an outline on `border-border`.
- **Cards and panels:** `bg-card text-card-foreground border-border`, `rounded-xl`.
- **Inputs and selects:** `bg-background border-input`, focus `ring-ring`, `rounded-lg`, a visible label above each field.
- **Badges, chips and destructive actions:** `bg-muted text-muted-foreground` pills; `bg-destructive text-destructive-foreground`, always confirmed.

## Do's and Don'ts

**Do**

- Use the theme's semantic tokens for every colour (`bg-background`, `bg-card`, `text-muted-foreground`, `border-border`).
- Give radius by role (controls `rounded-lg`, cards `rounded-xl`, pills `rounded-full`) and shadows by elevation.
- Lead with the screen's primary task and keep its controls next to what they change.

**Don't**

- Hardcode palette utilities or hex values that bypass the theme tokens.
- Use one radius or one shadow for everything.
- Fill space with invented sections, metrics or testimonials.
- Use raw palette utilities this theme rejects: `bg-zinc-`, `bg-gray-`, `bg-stone-`, `bg-slate-`, `text-white`, `border-zinc-`.

## Imagery

Images appear where they carry content (a product, a person, a place) and sit in `rounded-xl` frames; decorative stock is left out.

## Iconography

Line icons from lucide-react, inheriting the colour of the text they sit beside and sized to it (16px beside body copy, 20–24px as a standalone marker). Icons label and clarify; they never replace a word the reader needs.

## Motion

Motion is restrained: short entrance fades and state transitions (hover, open, expand) that confirm an action. Nothing loops and nothing gates content.

Every effect respects `prefers-reduced-motion`, and the page reads complete at rest: at the top of the page, with no pointer, in a screenshot or an export.
